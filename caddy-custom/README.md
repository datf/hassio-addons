# Home Assistant App: Caddy Custom

Caddy is a modern, cross-platform open-source web server and reverse proxy written in Go with automatic HTTPS certificate renewal built-in.

## About

This app allows you to run Caddy directly on Home Assistant and add any Caddy plugins you want straight from the configuration using `xcaddy`—supporting standard plugins, pinned versions, module replacements, and subpackages—with no need to compile Caddy manually or use the Caddy downloads page.
